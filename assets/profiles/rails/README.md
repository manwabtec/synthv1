# Rail profiles

One CSV per rail section, chosen by file name in the scene config. No measured rail
profile has been supplied. `rail_136re_placeholder.csv` (to be added with the rail
asset) approximates the general shape of a North American 136RE-class rail; it is a
PLACEHOLDER, not the standard's dimensions. Replace it with a sourced profile when
available, recording the source next to the file as for wheel profiles.
