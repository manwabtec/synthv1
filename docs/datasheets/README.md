# Hardware provenance

Keep camera, lens and laser source references here, including manufacturer,
model, document revision, URL/page, units and retrieval date. Mark each adopted
value as specified, measured, derived or assumed. Runtime values remain solely
in `configs/opticsrigs/`, not in a second hardware YAML library.

No manufacturer datasheets have been supplied. Existing demo parameters are
illustrative, not verified manufacturer values. Never commit restricted documents
without permission; source links and provenance notes can be stored instead.
